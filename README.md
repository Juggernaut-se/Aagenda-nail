# Agenda Nail V1.0
PWA leve para agenda de manicure.

## Rodar localmente
Abra a pasta no VS Code e use uma extensão/servidor local (por exemplo Live Server).
Não abra index.html diretamente como file://.

## Publicar
Pode ser publicado em GitHub Pages ou Cloudflare Pages.
Depois de publicado em HTTPS, abra no celular e use "Adicionar à tela de início".

## Observação
Os dados da V1.0 ficam no navegador/dispositivo usando IndexedDB. Faça backup manual antes de uso comercial.
